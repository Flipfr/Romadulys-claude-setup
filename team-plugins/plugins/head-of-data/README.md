# Head of Data

Ton Head of Data dans Claude. Analyse de données brutes + métriques SaaS complètes.

## Quand l'appeler

- Tu as un dump CSV / Excel et tu veux des insights actionnables
- Tu veux comprendre pourquoi tes métriques évoluent
- Tu veux un dashboard recurring SaaS (MRR, churn, CAC, LTV)
- Tu prépares un comité ou un investor update avec données

## Compétences (skills bundlées)

| Skill | Rôle |
|---|---|
| `data-analyst` | Insights + visualisations + dashboard |
| `saas-metrics` | Métriques SaaS complètes + cohort |

## Usage

```
/data
```

3 phases : brief → analyse → métriques SaaS → rapport actionnable.
