# Head of SEO

Ton Head of SEO dans Claude. **Domine une verticale SEO** : audit + topic cluster + articles + meta + maillage interne + schema.org en 1 seule commande.

## Quand l'appeler

- Tu lances un site et tu veux un plan SEO 6-12 mois pour atteindre la 1re page
- Tu accompagnes une mission "scaling SEO"
- Tu reprends un site existant et tu veux savoir quoi optimiser en priorité
- Tu veux structurer un topic cluster sans risquer la cannibalisation

## Compétences (skills bundlées)

| Skill | Rôle |
|---|---|
| `seo-audit` | Audit technique + contenu Next.js / Vercel |
| `seo-cluster-strategist` | Architecture pillar + 8-12 spokes |
| `seo-content-writer` | Articles 1500-3000 mots optimisés |
| `seo-meta-creator` | 5 variantes meta title + description |
| `seo-internal-linking` | Maillage interne sans cannibalisation |
| `schema-markup` | JSON-LD prêt à coller |

## Installation

```bash
cp -r "./head-of-seo" "~/.claude/plugins/head-of-seo"
```

Redémarre Claude Code.

## Usage

```
/seo
```

7 phases : brief → audit → cluster → articles → meta → maillage → schema.org → plan 6 mois.

## ⚠️ Règles critiques

- **Ne JAMAIS écrire d'articles avant l'audit** : l'audit Phase 1 révèle des problèmes techniques qui annulent l'effet du contenu
- **Cluster avant rédaction** : sinon cannibalisation garantie
