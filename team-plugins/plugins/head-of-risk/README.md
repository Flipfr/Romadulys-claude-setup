# Head of Risk

Sécuriser la boîte : identifier les risques, les couvrir, et tenir en cas de coup dur.

## Quand l'appeler

- Bâtir une cartographie des risques
- Préparer un comité des risques
- Vérifier la couverture assurantielle
- Monter un plan de continuité ou une cellule de crise

## Compétences (skills bundlées)

| Skill | Rôle |
|---|---|
| `cartographie-risques` | Familles de risques, cotation fréquence x gravité, matrice, traitement, contrôle interne |
| `assurances-continuite` | Couverture (RC pro, cyber, D&O), audit, PCA/PRA, gestion de crise |

## Installation

```bash
cp -r "./head-of-risk" "~/.claude/plugins/head-of-risk"
```

Redémarre Claude Code.

## Usage

```bash
/risk
```

Le flux part d'un cadrage rapide, dresse la cartographie des risques, vérifie assurances et continuité, puis livre une synthèse priorisée.

## ⚠️ Avertissement

Ce plugin ne remplace pas un courtier en assurances ni un avocat.
