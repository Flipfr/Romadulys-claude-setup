# Head of Academy

Ton Head of Academy / Formation dans Claude. Utilisable pour toute formation en ligne (focus auto-école possible).

## Quand l'appeler

- Tu construis une nouvelle formation (Code, Conduite, autre)
- Tu refais l'architecture pédagogique d'un module
- Tu mets en place le lifecycle email apprenant
- Tu optimises la landing de vente de la formation

## Compétences (skills bundlées)

| Skill | Rôle |
|---|---|
| `course-builder` | Architecture modulaire + scripts |
| `autoecole-expert` | Contenu certification + réglementation |
| `email-campaign` | Lifecycle apprenant |
| `ecommerce-optimizer` | Landing + pricing |

## Usage

```
/academy
```

5 phases : brief → architecture → contenu auto-école → email → landing → pack formation.
