# Head of People

Ton Head of People dans Claude. Recrutement, délégation, OKRs équipe, entretiens 1-1.

## Quand l'appeler

- Tu veux rédiger une fiche de poste qui attire les bons profils
- Tu es débordé et tu veux structurer ta délégation
- Tu prépares un trimestre avec OKRs équipe
- Tu prépares un 1-1 ou un steering important

## Compétences (skills bundlées)

| Skill | Rôle |
|---|---|
| `job-description` | Fiches de poste qui filtrent |
| `delegation-system` | Audit + matrice de délégation |
| `okr-builder` | OKRs équipe trimestriels |
| `meeting-prep` | Briefing + compte-rendu structuré |

## Usage

```
/people
```

Active 1-4 phases selon le sujet (recrutement / délégation / OKRs / meeting).
