# Head of Operations

Ton Head of Operations dans Claude. Cartographie process, SOPs, délégation, weekly review, OKRs ops.

## Quand l'appeler

- Tu veux structurer un process critique avant de le déléguer
- Tu veux un SOP suivable par n'importe qui (onboarding équipe)
- Tu veux mettre en place une routine weekly review
- Tu veux des OKRs ops alignés avec la boîte

## Compétences (skills bundlées)

| Skill | Rôle |
|---|---|
| `process-mapper` | Cartographie + SOPs |
| `delegation-system` | Matrice de délégation |
| `weekly-review` | Routine hebdo structurée |
| `okr-builder` | OKRs ops trimestriels |

## Usage

```
/operations
```

5 phases : brief → process → délégation → weekly review → OKRs → pack ops.
