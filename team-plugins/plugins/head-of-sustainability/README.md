# Head of Sustainability

Ton responsable RSE dans Claude : conformité CSRD et décarbonation, y compris quand un donneur d'ordre l'exige.

## Quand l'appeler

- Savoir si tu es concerné par la CSRD
- Répondre à un questionnaire ESG d'un client
- Lancer un bilan carbone
- Bâtir un plan de décarbonation

## Compétences (skills bundlées)

| Skill | Rôle |
|---|---|
| `csrd-esg-reporting` | CSRD, double matérialité, ESRS, taxonomie, notation ESG |
| `bilan-carbone` | GHG Protocol/ADEME, scopes 1/2/3, facteurs d'émission, plan de décarbonation |

## Installation

```bash
cp -r "./head-of-sustainability" "~/.claude/plugins/head-of-sustainability"
```

Redémarre Claude Code.

## Usage

```
/sustainability
```

Le flux cadre ta situation, enchaîne le reporting CSRD/ESG puis le bilan carbone, et produit une feuille de route durabilité.

## ⚠️ Avertissement

Les périmètres et seuils réglementaires (CSRD, BEGES) sont en évolution : à vérifier sur source primaire. Ce plugin ne remplace pas un cabinet spécialisé.
