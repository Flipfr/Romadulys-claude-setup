# Head of Sales

Ton Head of Sales / VP Sales dans Claude. Construit un **go-to-market B2B multi-canal** : analyse concurrentielle + script sales + outbound + LinkedIn + partenariats.

## Quand l'appeler

- Tu lances une offre B2B et tu veux un plan d'attaque commercial structuré
- Tu accompagnes un client en mission "scaling commercial"
- Tu veux un playbook sales cohérent pour onboarder un nouveau SDR
- Tu veux multiplier tes canaux d'acquisition de manière coordonnée

## Compétences (skills bundlées)

| Skill | Rôle |
|---|---|
| `competitor-analysis` | Cartographie marché + gaps |
| `sales-script` | Script discovery + objections + relances |
| `email-campaign` | Séquence outbound 4-6 touches |
| `linkedin-content-creator` | Social selling + pilier contenu |
| `partnership-outreach` | Stratégie partenariats + templates |

## Installation

```bash
cp -r "./head-of-sales" "~/.claude/plugins/head-of-sales"
```

Redémarre Claude Code.

## Usage

```
/sales
```

6 phases : brief → concurrence → script sales → outbound → LinkedIn → partenariats → plan 90j.
