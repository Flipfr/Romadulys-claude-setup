# Head of Product

Ton Head of Product dans Claude. Pilote le cycle Discovery → Delivery sur une feature ou un produit complet.

## Quand l'appeler

- Tu veux cadrer une nouvelle feature avant de partir en dev
- Tu prépares un kick-off produit avec ton équipe
- Tu dois rédiger un PRD propre pour aligner stakeholders
- Tu veux construire une roadmap 90j alignée avec des OKRs

## Compétences (skills bundlées)

| Skill | Rôle |
|---|---|
| `customer-interview` | Discovery JTBD |
| `competitor-analysis` | Cartographie marché |
| `product-manager` | PRD avec user stories |
| `roadmap-90-jours` | Gantt + jalons |
| `okr-builder` | OKRs trimestriels |

## Usage

```
/product
```

6 phases : brief → discovery → concurrence → PRD → roadmap → OKRs → pack consolidé.
